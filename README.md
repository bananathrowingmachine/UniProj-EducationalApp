UniProj-EducationalApp
=

All this assignment really told us was to make a educational app in c++ using QT editor, and make sure it used Box2D, a simplistic 2D physics engine for c++ somewhere in the project, so I don't have a pdf to give this time.

Since it was so open ended we all came up with a app that taught users how to make certain cocktails, where you can also throw all the ingredients around. The app should tell you the rest!

However do note just like UniProj-SpriteEditor, since it was made in QT that uses a funny "virtual file directory system" that actually just shoves every file into one unorganized directory, you'll probably need to take everything out of the neatly organized directories and just dump it in one folder, and then it should run. I hate how QT does this I really wish it didn't.
